# webfile

A simple, clean HTML page with a responsive layout.

## Features

- Sticky navigation bar
- Hero section with background image
- About, Features, and Contact sections
- Contact form powered by [Formspree](https://formspree.io)
- Social media links in the footer (Font Awesome icons)

## Usage

Open `index.html` in a browser — no build step required.

## Contact Form

Form submissions are handled by Formspree. To use your own endpoint, update the `action` attribute in the `<form>` tag in `index.html`.
